# E 组实验设计：顺序嵌入 vs 联合优化（回应 EIAW Table 9）

> 状态: 设计中 | 计划 W4-5 执行

## 1. 科学问题
EIAW (BDMA 2026) Table 9 声称"联合优化（水印+攻击一起优化）优于顺序嵌入（先攻击后水印）"。
我们的论文要验证：在人脸遮蔽场景下，**顺序嵌入 + 安全区域图 + 频域约束**是否不输联合优化。

## 2. 对照设计
| 方法 | 处理 | 预期 |
|---|---|---|
| E1: EIAW 式联合优化（简化复现） | 同时优化 FR 遮蔽损失 + DCT 水印损失 | 遮蔽+水印都最优 |
| D: 我们的顺序嵌入（Fawkes→安全图→WAM→频域） | 分步 | 遮蔽+水印接近 E1 |
| B: 朴素顺序嵌入（无安全图/频域） | 分步 | 遮蔽被破坏 |

## 3. 实现思路（简化）
EIAW 的水印是 DCT 域盲水印（mod 运算）。联合优化目标：
```
min δ  L_cloak(f(B+δ), f_orig) + λ * L_wm(DCT_decode(B+δ), msg)
```
- L_cloak: Fawkes 特征距离（extractor_2，TF）
- L_wm: DCT 水印解码（我们自实现，torch 可微）

困难：TF+torch 混合。方案：
a) 全 torch 实现 Fawkes 遮蔽（用 arcface34 代理提取器）→ 与 DCT 水印同一框架
b) 分步近似：Fawkes 遮蔽后，再做"水印感知的微调扰动"

## 4. 与 EIAW 的差异（写作要点）
- EIAW: 图像分类 + PGD + DCT 模运算水印
- 我们: 人脸识别 + Fawkes 遮蔽 + 神经网络水印（WAM）
- 我们的贡献: 顺序嵌入 + 空间安全图 + 频域约束也能达到联合优化效果，且实现更简单
