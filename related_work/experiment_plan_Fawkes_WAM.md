# 最小实验方案：可溯源隐私遮蔽人脸（Fawkes + WAM + 频域掩码）

> 目标：4 周闭环，验证"隐私遮蔽（对抗）与可验证水印（溯源）可共存"，产出 JCR Q2 论文的核心实验表。

## 1. 研究问题与动机

**痛点**：现有隐私遮蔽（Fawkes/LowKey）只让 AI 认不出你，但遮蔽图**没有任何可验证的溯源凭证**——别人可以拿着"你的遮蔽图"冒充你发布内容，无法问责。
**核心假设**：在遮蔽图中嵌入 WAM 水印，且只嵌在**人脸语义安全区域**（避开眼睛/鼻子等 FR 高敏感区），可同时保持"FR 认不出"与"水印可解码"。
**差异化**：EIAW 是"整图扰动+频域水印"在图像分类上的联合优化；我们验证"空间安全区域图 + WAM 神经网络水印"在人脸识别上的**顺序嵌入也能不输联合优化**（直接回应 EIAW Table 9 的结论）。

## 2. 实验设置

### 环境（单卡/CPU 可跑）
- Python 3.10 + PyTorch；`facenet-pytorch`（本地已有环境）
- Fawkes 官方代码（ICLR 2022，https://github.com/Secure-AI-Systems/Fawkes）
- WAM 官方代码+checkpoint（Meta，https://github.com/facebookresearch/watermark-anything，**第 1 周下载**）
- 数据：LFW 子集（本地已有 13,233 张 / 5749 身份），取 1000 张干净可识别样本即可

### 流水线
```
LFW 干净人脸 A
  → Fawkes 遮蔽（黑盒，feature squeeze 迭代）→ 遮蔽图 B（FR 认不出）
  → 安全区域图 R（FR 代理梯度定位高敏感区；无补丁故 S=(1−R)）
  → WAM 水印嵌入：C = B + α·S·(wm(B) − B)（变体D再叠加频域中低频掩码 M）
  → 输出遮蔽水印图 C
```

### 四组对照（关键实验表）

| 组 | 处理 | 回答的问题 |
|---|---|---|
| A | Fawkes 遮蔽（无任何水印） | 基线：遮蔽有效性与质量上界 |
| B | Fawkes + WAM **全局**嵌入 | 朴素方案：水印破坏遮蔽性的程度 |
| C | Fawkes + WAM **安全区域图**引导嵌入 | 安全图机制是否保住遮蔽性（本文创新点①） |
| D | C + **频域中低频掩码**（借鉴 EIAW） | 频域约束是否进一步保质量/水印率（创新点②） |

### 评估指标
1. **遮蔽有效性（FR 身份一致性）**：exact（仍被认成遮蔽目标/错误身份）/ drift / revert / not_detected —— 沿用 AdvFake 的 STATUS 体系
2. **水印检测**：TPR（像素级/图像级阈值）、32-bit 位精度、负样本 FPR
3. **不可感知性**：PSNR / SSIM / LPIPS（C vs A，遮蔽图 vs 遮蔽水印图）
4. **鲁棒性**：JPEG(50/80)、裁剪、亮度、几何变换 —— 重点看 JPEG（WAM 已知短板，本文要攻）

### 预期对照表（占位）

| 指标 | A | B | C | D |
|---|---|---|---|---|
| 遮蔽保持率（revert 率↓） | 100% / — | ~60–75% | **预期 ≥90%** | ≥90% |
| 水印 TPR（clean） | — | 100% | 100% | 100% |
| 水印 TPR（JPEG80） | — | ~20% | ~20% | **预期 ↑（频域中低频）** |
| PSNR (dB) | 参照 | ~38 | ~40 | **预期最高** |
| LPIPS | 参照 | ~0.01 | ~0.008 | **预期最低** |

**通过标准**：C 组遮蔽保持率 ≥90% 且水印 TPR ≥98%（clean）、JPEG80 显著优于 B 组 —— 则核心动机与两个创新点均成立。

## 3. 风险与兜底
- WAM 在 JPEG 下崩 → 若频域掩码救不回来，改 JPEG-aware 训练（把 JPEG 当增强噪声），作为创新点②的加强版
- Fawkes 遮蔽率低 → 换 LowKey 或降低遮蔽强度，保证 1000 样本中 ≥800 遮蔽成功
- 安全图 R 计算过重 → 先用代理梯度（arcface34 已有权重）粗定位，再小规模黑盒探测（沿用 AdvFake 的 hybrid 逻辑）

## 4. 时间线（4 周）
- W1：下载 WAM+Fawkes，跑通 A、B 两组，拿到"朴素嵌入破坏遮蔽性"的基线数字
- W2：实现安全区域图（C 组），跑 1000 样本
- W3：加频域掩码（D 组）+ JPEG/噪声鲁棒
- W4：补消融（α 强度、掩码比例）、整理对照表 → 进入写作
